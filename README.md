## Setup

Butuh Flutter 3.38 atau lebih baru.

```bash
git clone https://github.com/zidanristek/myportofolio_mobile.git
cd myportofolio_mobile
flutter pub get
flutter run -d chrome
```

Cek kode dengan `flutter analyze`.
